# reference/ 参考说话人目录

每个参考说话人由**同名**的两个文件组成（UTF-8 编码）：

```
reference/
├── speaker_zh.wav   # 参考音频（被克隆的音色）
├── speaker_zh.txt   # 该参考音频对应的文本内容
├── speaker_en.wav
└── speaker_en.txt
```

要求与建议：

- `.wav` 与 `.txt` 的 basename 必须完全一致，缺少 `.txt` 会直接报错。
- 参考音频建议：单人、无背景噪声/音乐、无混响，时长 3–15 秒（程序对 <2s 或 >30s 会给出警告）。
- 采样率不限（程序内部由上游模型处理），但建议 ≥16 kHz 的干净录音；音质越好，克隆相似度越高。
- `.txt` 中应写下参考音频里**实际说出的内容**。IndexTTS 2.5 的
  `IndexTTS2.infer()` 只需要参考音频（`spk_audio_prompt`），参考文本用于
  人工核对、批量管理并写入 manifest，保持其准确性有助于排查克隆效果问题。
- 本仓库不提供真实人声样例：请只使用**已获授权**的声音，禁止克隆未经许可的他人声音。

> 出于仓库体积与隐私考虑，`reference/*.wav` 已在 `.gitignore` 中忽略。
